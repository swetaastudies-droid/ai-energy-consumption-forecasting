START HERE

1. Extract this ZIP.
2. Open the extracted AI-Energy-Forecasting folder in VS Code.
3. Download the UCI dataset and put household_power_consumption.txt in data/raw/.
4. Open VS Code Terminal in the project root.
5. Create and activate .venv (instructions are in the main README.md).
6. Install dependencies: python -m pip install -r requirements.txt
7. Run: python main.py

If Python 3.13 is installed, use `py -3.13 -m venv .venv` on Windows to create the environment with that version.
